#  Bank Management System

A **Bank Management System** is a console-based application that simulates basic banking operations such as account creation, deposits, withdrawals, and account management.

This project is designed to demonstrate **core programming concepts**, including file handling, data management, and user interaction.

---

##  Project Overview

The system allows users to perform essential banking operations through a menu-driven interface.

It replicates real-world banking functionality in a simplified manner, helping users understand how banking systems manage customer data and transactions.

---

##  Features

-  Create a new bank account  
-  Deposit money into an account  
-  Withdraw money from an account  
-  Check account balance  
-  View account details  
-  Delete/close account *(if implemented)*  
-  Persistent data storage *(file-based / program memory)*
